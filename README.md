
# HER2 Protein Sequence Analysis

## Project Overview
This project analyzes the human HER2 (ERBB2) protein
sequence using Python and Biopython.

## Research Objective
To study the sequence length, theoretical molecular weight,
and amino acid composition of HER2.

## Data Source
- Database: UniProt
- Accession: P04626
- Protein: HER2 / ERBB2_HUMAN
- URL: https://rest.uniprot.org/uniprotkb/P04626.fasta

## Results
- Sequence length: 1255 amino acids
- Molecular weight: 137909.068 Da
- Molecular weight: 137.909 kDa

## Methods
1. Retrieved the HER2 FASTA sequence from UniProt.
2. Analyzed the sequence using Biopython.
3. Calculated theoretical molecular weight.
4. Counted amino acid occurrences.
5. Calculated amino acid percentages.
6. Generated a composition bar graph.

## Project Files
- HER2_Protein_Sequence.fasta: Protein sequence
- HER2_Amino_Acid_Composition.csv: Amino acid results
- HER2_Amino_Acid_Graph.png: Composition graph
- HER2_Research_Report.md: Research report
- README.md: Project documentation

## Tools
- Python
- Biopython
- Pandas
- Matplotlib

## Limitations
This is a computational sequence analysis.
It does not establish drug effectiveness or clinical outcomes.
The calculated molecular weight is theoretical and does not
account for post-translational modifications.
